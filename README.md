# Murith Prévoyance — maquette du site

Site statique (HTML/CSS/JS), sans dépendance de build. Ouvrir `index.html` (français) ou `en/index.html` (English).

Pages FR : `index`, `obseques`, `garanties`, `facilites-de-paiement`, `questionnaire`, `infos-pratiques`, `contact`, `mentions-legales`, `mon-compte` (connexion), `espace-client` (démo).
Pages EN : dossier `en/` (mêmes pages, URL en anglais).
Styles et scripts partagés : `assets/`.

L’espace client est une **démonstration** : données fictives, aucune authentification réelle.
